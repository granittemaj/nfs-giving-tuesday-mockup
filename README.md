# Giving Tuesday hub · mockup

A review mockup of the proposed Giving Tuesday hub for [wearenotforsale.org](https://wearenotforsale.org), built in the
site's own design system. **Not the live site.** Pages are marked `noindex`.

- Copy, page list and illustrations: the content team's Giving Tuesday package, unchanged except
  for two things: the Gift of Giving button is a plain link to the donate page (as the package's
  handover asks), and an editorial label ("Supporting line:") that had leaked into the Donate
  page copy was removed.
- Design: the papingu theme's own `styles.css`, `app.js` (header, footer, newsletter, search),
  fonts and the Learn explainer components. `assets/css/gt.css` adds only what the theme has no
  component for: the guide contents rail, tables and the Gift of Giving card.
- Header search queries the live site. The newsletter form is switched off.
